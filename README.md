# 🛒 Gestor de Productos CLI (Pre-Entrega TechLab)

Herramienta de consola desarrollada en Node.js para la gestión de productos de una tienda en línea, interactuando con la FakeStore API mediante peticiones asíncronas y ESModules.

---

## 🚀 Requisitos Previos

* Tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior recomendada para soporte nativo de `fetch`).

---

## ⚙️ Configuración Inicial

1. Clona este repositorio o descarga los archivos del proyecto.
2. Asegurate de tener configurado el archivo `package.json` con las siguientes propiedades obligatorias:
   ```json
   {
     "type": "module",
     "scripts": {
       "start": "node index.js"
     }
   }
